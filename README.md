De Newton a Coulomb 🍎⚡

Web interactiva para Física y Química (2º ESO) que explora las similitudes entre la fuerza gravitatoria y la eléctrica.

🚀 Descripción

Este recurso educativo permite al alumnado experimentar con las leyes fundamentales que rigen el universo:

Ley de Gravitación Universal (Newton): La fuerza que mueve el cosmos.

Ley de Coulomb (Electricidad): La fuerza que une la materia.

Diseñado para ser ligero, accesible desde cualquier dispositivo y sin necesidad de instalación.

✨ Características

Simuladores Propios: Modifica masas, cargas y distancias para ver los cambios en la fuerza en tiempo real.

Laboratorios Virtuales: Integración de simulaciones oficiales PhET Colorado.

Autoevaluación: Ejercicios rápidos de validación de conceptos y unidades.

Diseño Intuitivo: Interfaz clara dividida en pestañas temáticas.
